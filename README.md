# BDA_Project

This project analyses the environmental niche of:
- Dactylorhiza sambucina
- Bombus terrestris

The pipeline includes:
- Intermediate project :
    - Data collection (GBIF + iNaturalist)
    - Environmental data extraction
- Final project :
    - PCA
    - Environmental comparison
    - Random forest
    - Summary panel
    - Advanced plots

Main script: inst/my_project.r
